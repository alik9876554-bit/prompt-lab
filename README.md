# Prompt Lab — From Bad Prompts to Better Results

A practical Prompt Engineering project demonstrating how different prompting techniques can improve AI-generated results.

## Project Goal

The goal of this project is to explore how prompt structure, context, constraints and examples affect the quality and consistency of AI-generated content.

The project is designed as a practical experiment that can also be used as an educational example for teenagers learning Generative AI.

---

## What I Explore

- Prompt Engineering
- Structured Prompts
- Few-shot Prompting
- Role and Context

- Output Formatting
- AI-generated storytelling
- Evaluation of AI outputs

---

## Main Experiment

The project compares four approaches to the same task:

### 1. Bad Prompt

A simple and vague instruction.

### 2. Improved Prompt

Additional context, requirements and constraints.

### 3. Structured Prompt

The instruction is organized into clear sections:

`ROLE → TASK → CONTEXT → AUDIENCE → CONSTRAINTS → OUTPUT`

### 4. Few-shot Prompt

The prompt includes an example of the desired output.

### Experiment Flow

```text
Bad Prompt
     ↓
Improved Prompt
     ↓
Structured Prompt
     ↓
Few-shot Prompt
     ↓
Compare Results
     ↓
Evaluate Quality
```

---

## Practical Example

The main experiment focuses on creating a short animated film about a teenager who dreams of becoming an artist.

The AI is asked to develop:

- story concept
- characters
- scenes
- emotions
- dialogue
- visual descriptions
- camera directions

The experiment demonstrates how additional context and examples give more control over the generated result.

---

## Key Learning

A good prompt is not simply a long prompt.

Effective prompting is about giving the AI enough information to understand:

**What to do → Why → For whom → Under which conditions → In what format**

Adding structure and examples can make AI outputs more relevant, consistent and controllable.
